## API surface

There is none. As of 2026-08-22 GRC publishes:

- No developer portal, API reference, or getting-started guide
- No OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema
- No SDKs or client libraries on npm, PyPI, RubyGems, crates.io, Maven Central, NuGet or pkg.go.dev
- No MCP server and no A2A agent card
- No /.well-known/ documents on any GRC host

GRC's only software product is Systems Manager, an on-premises appliance that gives an
operator a single monitoring interface across connected ICEraQ and ICEtank systems over
the customer's own network. Its interfaces are documented as industrial data center
protocols — Modbus TCP, SNMP and BACnet for DCIM/BMS integration — not as a web API.
Nothing about those interfaces is published at a public URL.

The only machine-readable surface reachable on a GRC host is the generic WordPress core
REST API index at https://www.grcooling.com/wp-json/ (HTTP 200). Its 383 routes belong
entirely to WordPress core and third-party plugins (WP Engine, Contact Form 7, HubSpot
leadin, Wordfence, Elementor, Redirection, MonsterInsights). There is no GRC-authored
namespace. It is the marketing site's CMS, not a GRC product API, and it is deliberately
not registered as one in this profile.
